# 3D Photo Synthesis Engine

> 從一對 **彩色圖 + 深度圖**，在瀏覽器裡合成可用滑鼠拖曳的 **3D 照片**
> （Facebook 3D Photo 式的**小角度視差**）。

一切運算在你自己的機器完成——無需雲端、無需帳號。

> **專案狀態：已結案（2026-08-16）。**
> 「視差模式」已完成並通過驗收，可正常使用；「LDI 分層補洞」實驗未達品質目標，
> 保留在介面上但不建議依賴；「Mesh 模式」是進階匯出選項。
> 專案不再新增功能。完整結案檢討見
> [`docs/LDI_retrospective.md`](docs/LDI_retrospective.md) 與
> `~/.claude/outputs/retrospectives/retrospective-3D-photo-engine-2026-08-16.md`。

## ✨ 特色

- 🖼️ **輸入單純**：一張 RGB 圖 + 一張深度圖
- 🖱️ **即時互動**：滑鼠**拖曳**產生前後景視差，放開自動平滑回正
- 🎚️ **可調效果**：視差強度、邊界穩定度即時可調
- 🔒 **本機運算**：影像不離開你的機器
- 🌐 **跨平台**：純網頁前端，任何支援 WebGL 的現代瀏覽器

## 🚀 開始使用

### 需求

- **Windows**（提供一鍵腳本）或任何能跑 Python 的系統
- [Python](https://www.python.org/downloads/) 3.10 以上
- [Node.js](https://nodejs.org/) 18 以上
- 支援 WebGL 的現代瀏覽器（Chrome / Edge / Firefox）

### 安裝與啟動（Windows 一鍵）

1. 下載或 clone 本專案。
2. 雙擊 **`engine.bat`**，選擇 `1. install`（首次安裝，會建立環境並安裝依賴）。
3. 安裝完成後再次執行 `engine.bat`，選擇 `3. run`。
4. 瀏覽器開啟 **http://127.0.0.1:5173**。

> 命令列也可：`engine.bat install` 然後 `engine.bat run`。

### 其他系統（手動）

```bash
# 後端
python -m venv .venv
.venv/bin/pip install -r requirements.txt          # Windows: .venv\Scripts\pip
.venv/bin/python -m uvicorn backend.app:app        # 後端啟動於 :8000

# 前端（另開一個終端機）
cd frontend && npm install && npm run dev          # 前端啟動於 :5173
```

## 📖 操作流程

1. 選擇 **RGB 圖片** 與 **深度圖**（也可直接按「載入測試範例圖」）。
2. 選擇**檢視模式**（預設為視差模式，見下表）。
3. （選用）展開「進階參數」調整效果。
4. 按 **「合成 3D 照片」**。
5. 在畫面上**按住左鍵拖曳** —— 前景與背景往反方向移動，放開後平滑回正。

### 三種檢視模式

| 模式 | 這是什麼 | 建議 |
|---|---|---|
| **視差模式**（預設） | 平面 + 深度位移，最輕最快（約 1.9 MB、近即時），沒有破圖 | **正常使用選這個** |
| **LDI 分層補洞** | 實驗性：沿深度斷崖分層並預先補洞，想在拖曳時露出更可信的背景 | 實驗未達目標，與視差模式差異不明顯且大面積遮擋處會糊 |
| **Mesh 模式** | 真的建出 3D 網格，可下載 `.glb` 拿去別的 3D 工具用 | 只在需要匯出時用；可勾「自由旋轉視角」看真 3D 結構（會露出側面破洞） |

### 進階參數

| 參數 | 作用 | 適用模式 |
|---|---|---|
| **視差強度** | 值越大前後景分離越明顯 | 視差 / LDI |
| **邊界穩定** | 值越大物件邊緣殘影越少，但視差越保守 | 視差 / LDI |
| **LDI 分層數**（2–3） | 層數越多縱深層次越細但越慢 | LDI |
| **斷邊百分位** | 值越高越少邊緣被裂開 | Mesh |
| **近遠視差** | 網格的前後景分離程度 | Mesh |
| **自由旋轉視角** | 改用自由軌道相機看真 3D 結構 | Mesh |

### 深度圖怎麼來？

深度圖是一張與彩色圖同視角、以灰階表示遠近的圖片。可由 AI 深度估算工具
（MiDaS、Depth Anything）從單張照片生成，或由具深度感測的相機取得。

**不必擔心亮暗方向**：本引擎會自動判斷你的深度圖是 disparity（近=亮，ML 模型慣例）
還是 metric（近=暗），並轉成一致的語意。若結果的前後景剛好相反，那就是這個自動判斷
猜錯了——這是已知的弱點（判斷門檻只在少量樣本上校準過）。

> 介面上的「自動估深」核取方塊目前是**停用**的佔位：後端的深度估算器接口已就緒，
> 但沒有接任何模型，未提供深度圖時 `/parallax` 會回 422。

## ❓ 常見問題

**Q：拖曳時物件邊緣冒出旁邊的顏色（殘影）？**
A：把「邊界穩定」調大、或把「視差強度」調小。玻璃與半透明區域的深度本身就不可靠，
這部分是原理上的限制，調不掉。

**Q：Mesh 模式轉到側面會看到破洞？**
A：正常。單張照片沒有拍到物件背後，側面本來就沒有資料。這也是本專案最後沒能解決的問題。

**Q：支援哪些圖片格式？**
A：RGB 支援 PNG / JPG；深度圖支援 PNG（8 或 16 位元）與 TIFF。
RGB 與深度圖解析度不同時會自動對齊。

**Q：我的影像會被上傳到網路嗎？**
A：不會。前後端都跑在你本機。
